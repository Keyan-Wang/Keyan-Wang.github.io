# Keyan Wang | Personal academic website

A personal academic homepage covering biography, education, research interests,
published articles, ongoing projects, research code, and contact links.

## Pages

- `index.html`: personal introduction, selected publications, research interests,
  education, and ongoing work.
- `about.html`: biography and education.
- `research.html`: cancer cell states, therapeutic strategies, and computational oncology.
- `publications.html`: three verified journal articles with full author lists,
  authorship roles, DOI and PubMed links, and downloadable BibTeX citations.
- `projects.html`: published research themes and ongoing work.
- `project.html`: the MTAP research and Python course project.
- `data-code.html`: research code and reproducibility documentation.
- `contact.html`: affiliation and public contact links.

## Publish on GitHub Pages

1. Use the public repository **Keyan-Wang.github.io** in the Keyan-Wang account.
2. Upload the complete contents of this archive to the repository root, keeping
   the `assets/` directory intact. `index.html` must be at the root.
3. For an existing website, update the same-named files and add the new pages.
   Keep unrelated repository files.
4. Open **Settings > Pages** and choose **Deploy from a branch**.
5. Select **main**, **/(root)**, and click **Save**.
6. After deployment, use **Visit site** in Settings to open the public website.

The standard personal-site address is `https://keyan-wang.github.io/`.
Keep this personal website separate from the `mtap-rna-prediction` research repository.
The MTAP project remains one part of the academic portfolio.

## Technical details

Static HTML, CSS, JavaScript, and original decorative SVG artwork. No package
installation or build process is required. All visual assets and fonts are local.
Open `index.html` directly or run `python -m http.server 8000` for a local preview.

The visual direction is inspired by https://ustc-cbio.github.io/.
The layout, copy, wordmark, and decorative artwork are independently implemented.
CBIO Lab logos, photographs, and staff contact details are not included.
